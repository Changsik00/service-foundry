# @repo/biome-config

> 모노레포 공유 Biome 린트·포맷 프리셋 — 모든 패키지·앱의 `biome.json` 기반 설정.

## 설치 / import

```json
// 각 패키지의 biome.json
{
  "extends": ["@repo/biome-config/base"]
}
```

## 핵심 export

- `@repo/biome-config/base` (`base.json`) — 전체 모노레포 공통 Biome 규칙 프리셋
