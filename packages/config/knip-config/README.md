# @repo/knip-config

> 미사용 export·의존 탐지를 위한 공유 Knip 설정 프리셋.

## 설치 / import

```json
// 각 패키지 또는 루트의 knip.json
{
  "extends": "@repo/knip-config/base"
}
```

## 핵심 export

- `@repo/knip-config/base` (`base.json`) — 워크스페이스별 entry/project 패턴 및 ignoreDependencies 기본 설정
