# @repo/frontend-auth-http

> 백엔드 auth API를 `CoreAuthSDK` 계약으로 감싸는 HTTP 어댑터 — 현재 계획된 stub (미구현).

> **상태**: 이 패키지는 계획된 stub이다. `package.json`이 없고 소스 파일도 없다. Firebase/Supabase 외 자체 백엔드 JWT 인증이 필요할 때 구현 예정이다.
